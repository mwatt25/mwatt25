## How I work

I tend to start with the actual human problem first:

1. What is making the work harder than it needs to be?
2. What decision does the learner, educator, or user actually need to make?
3. What information or support should appear at that moment?
4. What can technology handle without removing human judgment?
5. How will we know the experience is useful?

That approach has shaped work across educator professional learning, early literacy, credential support, AI readiness, and implementation.
